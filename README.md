# simpleTVCast

## 介绍
简单的电视投屏工具，支持桌面镜像和视频投屏

simpleTVCast是一个简单的电视投屏工具，可以将电脑桌面和电脑本地视频资源投屏到电视上进行播放。
（支持联网的智能电视开机即可投屏，无需电视打开投屏配置界面）

## 为什么要开发这个软件
现在市面上的投屏工具要么需要电视插入一个投屏连接器，要么就是必须进入电视的投屏界面，选择安卓、ios、平板等模式下，才能允许手机、平板和电脑进行投屏，以上这些都可以省略，不需要这么麻烦。
这一次，我们让电视投屏回归原生和纯粹。
只要电视在开机联网状态下，保证在同一个网络下，都可以直接投送桌面镜像和视频文件到电视上立刻播放，无需电视端任何操作，也不需要电视端同意，强制投屏到电视。

## 软件架构

采用dlna投屏，只要电视在开机联网状态下，都可以直接投送桌面镜像和视频文件到电视上立刻播放，无需电视端任何操作。

#### 安装教程

1.  直接打开exe即可，无需安装

#### 使用说明

打开程序后会自动扫描内网支持dlna投屏的设备

镜像投屏 点击镜像投屏，将电脑桌面屏幕图像实时投射到电视上
视频文件投屏 选择视频目录后选择对应视频，即可点击投屏将视频投射到电视上播放
