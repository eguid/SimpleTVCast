QUICK START / 开始使用

三步完成第一次投屏

电视只需开机并联网，无需安装任何 App。

  1. 1

    打开软件

    从桌面或开始菜单启动简单电视投屏，确认服务状态正常。

  2. 2

    等待发现设备

    软件会自动搜索同一局域网内的电视或投影设备。

  3. 3

    选择设备并投屏

    点击设备旁的投屏图标即可开始，随时可以停止或切换。
