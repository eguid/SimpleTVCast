GUIDE / 使用教程

三步，把电脑画面投到电视

电视端无需安装任何 App：把电脑和电视连到同一网络，选好设备点一下「开始投屏」就行。

01 / 准备工作

先确认这四件事

大多数投屏失败，都是因为电脑与电视不在同一网段，或电视的投屏开关没有打开。

01

系统环境

支持 Windows Vista 及以上系统，Windows 7 / 8 / 10 / 11 均可运行，无需安装 Java 环境。

02

网络环境

电脑与电视连入同一局域网：同一 Wi-Fi 或同一有线网络都可以，建议优先使用有线或 5GHz Wi-Fi。

03

显示设备

支持 DLNA / AirPlay 的智能电视、投影仪、电子白板、智能音箱或投屏器，开机联网即可。

04

软件安装

绿色版解压即用，双击目录内的 SimpleTVCast.exe 运行；安装包双击安装，自动创建桌面快捷方式。

02 / 快速上手

打开软件，点一下就能投

全过程只有「选择设备」和「开始投屏」两步操作，没有任何学习负担。

  1. 1

    下载并运行

    下载 zip 解压后双击 SimpleTVCast.exe；或运行 msi 安装包完成安装后打开软件。

  2. 2

    等待发现设备

    软件会自动搜索同一局域网内的显示设备，设备列表出现电视名称或图标即表示发现成功。

  3. 3

    选择设备并开始投屏

    选中目标设备后点击「开始投屏」，按钮会变为「停止投屏」，可随时停止或切换设备。

提示：电视只需要开机并联网，无需打开投屏配对界面。部分运营商机顶盒或个别电视型号，需要用遥控器手动开启「无线投屏 / DLNA」开关。

03 / 投屏方式

六种投屏方式怎么用

不同场景选择不同方式，在软件内切换即可；互相独立的功能可以同时使用。

桌面镜像

实时采集桌面并低延迟投到电视，适合教学演示、会议展示与游戏副屏。

  • 选择要投送的显示器或窗口
  • 可调分辨率、帧率与码率
  • 系统声音随画面同步投送

PPT 演示投屏

为课件与会议报告设计的演示投屏，设备列表显示为投影幕布图标。

  • 按设定帧率推送，长时间演示更省资源
  • 适合教师课件与会议室报告
  • 与实时桌面镜像互斥，二选一使用

本地多媒体

把电脑上的视频、音乐与图片文件直接投到电视播放。

  • 选择目录或文件后自动扫描媒体
  • 支持连续投屏与图片轮播
  • 勾选后单个文件无限循环播放
  • 不支持的编码自动转换后投送

网络流媒体

网络直播、网络视频、网络音乐与网络图片地址直接投送。

  • 支持 RTSP、RTMP、HTTP-FLV、HLS、Dash
  • 粘贴地址即投，自动保存历史（最多 20 条）
  • 可自动读取剪贴板中的地址

手机投送到电脑

把手机、平板的相册与视频投到已安装本软件的电脑上。

  • 手机端无需安装任何软件
  • 相册或视频 App 点「投屏」选择电脑即可
  • 支持 DLNA 与 AirPlay 被动接收，可多设备同时投送

电脑投电脑

局域网内把另一台电脑的桌面或多媒体投送到本机，用于屏幕分享。

  • 接收端需在软件中开启接收功能
  • 仅共享画面与多媒体内容
  • 不是远程桌面，不支持键鼠控制

04 / 常见问题

投屏遇到问题？

先看这里，大部分问题都能自助解决；仍无法解决可加 QQ 群 1092312834 反馈。

电视列表里找不到设备怎么办？

确认电脑与电视处在同一网段：同一路由器下的 Wi-Fi 与有线网络通常互通，不同路由器或访客网络可能互相隔离。电视需开机联网；部分机顶盒或电视型号需要用遥控器手动开启「无线投屏 / DLNA」开关。

电视上需要安装 App 吗？

不需要。软件通过 DLNA / AirPlay 协议直接投送，电视端无需安装任何软件，也无需提前配对。

投屏画面卡顿或延迟高怎么办？

镜像投屏可在全局配置中调低分辨率、帧率或码率；尽量让电脑与电视接入同一路由器，优先使用有线网络或 5GHz Wi-Fi，并关闭占用带宽的后台下载。

视频格式电视不支持怎么办？

软件支持自动转换格式：mkv、avi、AV1 等电视不能直接播放的编码会自动转码后再投送，投屏前勾选「自动转换格式」即可。

提示「非法的控制地址」导致投屏失败？

该问题已在 6.0.3 版本修复，升级到最新版即可。若仍然出现，欢迎加 QQ 群 1092312834 提供电视品牌与型号。

可以同时投屏到多台设备吗？

可以。软件不限制投屏台数与画质、码率，多台显示设备可以同时接收；同一台电脑也可以分别向不同设备投送内容。

手机可以投到电脑吗？

可以。安卓、iOS 与平板通过 DLNA / AirPlay 把画面或媒体投送到已安装本软件的电脑，手机端无需安装软件，但投送端与接收端需在同一局域网。

软件收费吗？会上传数据吗？

完全免费、可商用，无广告，不限制功能与投屏台数；软件不上传任何个人信息、投屏内容或使用数据，可自行用网络监控工具验证。

现在开始第一次投屏

下载后无需任何设置，选好设备点一下「开始投屏」即可。
